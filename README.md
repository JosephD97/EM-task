  Тестовое задание на позицию DevOps

Простое веб-приложение работающая на cвязке Python + Nginx (в качестве reverse proxy), и развернутое через Docker Compose.

Описание схемы
  - Backend: Python-сервер (http.server), слушает порт 8080. Порт закрыт для внешней сети.
  - Nginx: Принимает запросы на 80 порту и перенаправляет их на бэкенд по имени сервиса.

Как запустить
  Нужно запустить команду в корне проекта:
    docker compose up --build
